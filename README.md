# Управление движением денежных средств (ДДС)

Веб-приложение для учета, управления и анализа поступлений и списаний денежных средств.

## Функциональность

### Записи ДДС
- Создание записей с полями: дата, статус, тип, категория, подкатегория, сумма, комментарий
- Редактирование и удаление записей
- Просмотр списка всех записей с пагинацией
- Фильтрация по дате, статусу, типу, категории, подкатегории

### Справочники
- Управление статусами
- Управление типами
- Управление категориями (привязаны к типам)
- Управление подкатегориями (привязаны к категориям)

## Технологии:

- Backend: Django 6.0.6
- Database: SQLite
- Frontend: HTML, CSS, Bootstrap 5, JavaScript (jQuery)

## Установка и запуск

1. Клонирование репозитория

```bash
git clone https://github.com/AlexSkoruk/название-репозитория.git
cd cashflow_project

2. Создание виртуального окружения
Windows:

```bash
python -m venv venv
venv\Scripts\activate

3. Установка зависимостей

```bash
pip install -r requirements.txt

4. Настройка базы данных

```bash
python manage.py makemigrations
python manage.py migrate

5. Создание суперпользователя

```bash
python manage.py createsuperuser

Далее следуйте инструкциям для создания администратора. Введите Username - имя пользователя, Email address - адрес электронной почты, Password - пароль, Password again - повтор ввода пароля.

6. Запуск сервера

```bash
python manage.py runserver
Откройте в браузере: http://127.0.0.1:8000/

7. Доступ к админ-панели
После запуска сервера перейдите по адресу:
http://127.0.0.1:8000/admin/
